# Data Analysis Project

🏴󠁧󠁢󠁥󠁮󠁧󠁿 Academic Data Analysis Between 2022 - 2024

<br>
This project's goal was to create an analytical summary about the following academic data (https://dados.gov.br/dados/conjuntos-dados/12-alunos).

<br>
The dataset it's a CSV file, where `Pandas` is used to make an exploratory analysis, `SQLAlchemy` is used to convert the CSV file that was edited to a SQL database, `FastAPI` is used to create an API and access the database created and extract the necessary data, `Pytest` is used to perform tests, and `Streamlit` for the dashboard creation with the obtained insights according to the database.

I was able to exercise these skills: 

* Data Analysis;
* Data Manipulation with SQL; 
* Creation and use of API;
* Testing;
* Interactive Dashboard Creation;
